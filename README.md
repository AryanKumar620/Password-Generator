🔐 Password Generator
A simple and customizable password generator built with HTML, CSS, and JavaScript.
Users can set password length and choose to include uppercase letters, lowercase letters, numbers, and special characters.

Features:

1. Adjustable password length (1–30 characters)

2. Toggle inclusion of:
  a. Uppercase letters
  b. Lowercase letters
  c. Numbers
  d. Symbols

3. Copy-to-clipboard functionality

4. Clean and responsive UI
